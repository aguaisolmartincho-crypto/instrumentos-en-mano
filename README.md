# Música en tus Manos — Android v2

Marketplace de instrumentos musicales, preparado para evolucionar a una aplicación online.

Incluye:
- catálogo
- búsqueda
- categorías
- fichas de producto
- carrito
- publicación de productos
- estructura para vendedores y checkout

Pendiente para producción:
- backend/base de datos
- cuentas y autenticación
- almacenamiento de imágenes
- Mercado Pago
- cálculo/gestión de envíos
- chat
- panel administrativo
- políticas, privacidad y términos
- firma y publicación en Google Play
